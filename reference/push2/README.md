Ableton's official Push 2 hardware spec, pulled from
`github.com/Ableton/push-interface` for offline reference. Source of truth
for CC/note numbers, LED semantics (RGB vs white palette fields), and the
screen protocol - cross-check here before trusting DrivenByMoss's constants
or guessing.

- `Push2-map.json` - full CC/note map for pads, buttons, encoders.
- `AbletonPush2MIDIDisplayInterface.asc` - full MIDI + display protocol doc.
